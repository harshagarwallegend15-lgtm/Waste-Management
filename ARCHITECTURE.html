⚙️ Tech Stack

Frontend

Vanilla HTML/CSS/JS — No framework. Glassmorphism UI, dark theme, responsive.

Backend

Node.js + Express on Vercel Serverless functions.

Database

Supabase (PostgreSQL) with RLS policies, Realtime subscriptions.

Authentication

Supabase Auth — Email/password + Google OAuth + email verification.

AI Vision

Groq API — qwen/qwen3.6-27b (photo), llama-3.3-70b (chatbot).

Storage

Supabase Storage — waste-photos bucket (public), before/after images.

i18n

5 Languages — English, Hindi, Kannada, Tamil, Bengali.

Realtime

Supabase Realtime — Postgres CDC → live dashboards + 8s polling fallback.

Device APIs

Geolocation, getUserMedia (camera), Web Speech API (voice).

CI/CD

GitHub Actions (Node 20/22 matrix) → Vercel auto-deploy on push.
